## What is proved

`G1_KT lab n (hK : AllKT lab n) (hB : BdryOK lab n)`: if every unit triangle of `T_n` is a KT piece
(ccw rotation of 000, 111, (10,0,1)) and the boundary carries no 10, then there is a 0-lift `f`
(`PuzzleLift`) and an `m` with `f(n,0) = f(0,0) + (m,0)` and `N₀ = [f(0,0) + m·T₁]`. Nothing is
assumed beyond KT-ness.

Structure:
1. `coch lab`: the Λ₀-cochain. A 0-edge gets its vector, a 1-edge gets 0, and a 10-edge gets the value
   that the up-triangle containing it forces (`c(cls0) + c(cls2) = c(cls1)`). So closure on up-triangles
   holds by construction (`triVal_closed`, decide).
2. `rhombus_rule_c0/c1/c2` (decide): the down-triangle across an edge assigns that edge the same
   value. This is tex Lemma chir (b), the half-turn. Down closure is `triVal_closed_down` (decide).
   Together they give `closed_of_KT`.
3. `integ_exact`, stated abstractly for any `c : Edge → ℤ²`: closure on every unit triangle of
   `T_n` ⇒ `c` is the coboundary of the row-path integral `integ c` (up the left side, then along
   the row). Proof by induction along rows: no topology, no cycle space.
4. `puzzleLift_of_KT`, then `G1_KT` via the existing `fstar_bd_Tn` and `G1_puzzle`.

## Correction to the brief: chirality enters as *consistency*, not as KT's chirality

The brief predicted that the lift would fail on mirrored labellings. **It does not.**
- `rhombus_rule_mirror` (decide): with mirror pieces throughout, the rhombus rule also holds.
  Lemma chir (a) explains it: up- and down-triangles read their classes in the same cyclic order,
  so either chirality, used consistently, survives the half-turn.
- Census, `scratch/q597_d1_check.py`, running this exact construction on n = 1, 2, 3:
  KT puzzles lift 2/2, 5/5, 14/14; consistent-mirror labellings lift 2/2, 5/5, 14/14; mixed
  (up-triangles KT, down-triangles mirror) lift only 2/2, 2/5, 2/16.
- `rhombus_rule_mixed_fails` (kernel): KT up `(1,10,0)` glued along its class-2 10-edge to a mirror down
  `(1,0,10)` gives that edge `(0,1)` from one side and `(-1,0)` from the other.

So the honest statement is that D(1) uses a **consistent** chirality. The registry's G1 mirror
census ("582 lifting mirror labellings", 11-24) implies some mirror labellings do not lift. That is
consistent with this only if that census mixed chiralities triangle by triangle. **Not checked
here**; flagged for REVIEW/DREAM.
