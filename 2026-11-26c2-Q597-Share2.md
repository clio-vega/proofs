## Theorem (Share₂, the second handshake)
Assume (S) (termination, Purbhoo mosaic, engine rule S1–S4) and **(H1)**: J_E takes a step at p_E+1 (computed on every
record). In a diverging B/C pair with roles L (contact step (1,a_{T_L})) and E:
1. Oth(E₁) = Oth(L₁) = {one square, one triangle}, M0 tiles outside both contact hexagons.
2. E₁ removes exactly one tile of H_L (a triangle) and none of H_E ∪ C(E₀) besides its rhombus; symmetrically for L₁.
3. Exactly one of E₁, L₁ is a b-step. Case b: L₁=(1,b), E₁=(0,a_{T_L}), and they create a common class-0 rhombus R* and a
   common triangle. Case a: L₁=(1,a_{T_E}), E₁=(0,b), no common created tile.

**Proof.** Lemma fin (new, from MU+REM+CRE): a journey never removes a non-rhombus tile it created, so every non-rhombus
tile it removes is an M0 tile, removed once. Hence N ∪ G(E₁) ∪ G(L₁) ⊂ M0 and is pairwise compatible. Lemma loc2 (finite,
exhaustive, exact read of the 12-configuration table): with Thm share (common square), Prop orient and Lemma word, only
4 contact pairs × 3 × 3 = 36 quadruples are possible; M0-tiling compatibility kills 28 (each role's own a-type at step 1
overlaps the hexagon triangles; the (a,a) and (b,b) pairings put overlapping squares on M0). On the 8 survivors, 1–3
hold. Case a/b ↔ type of L₁ via BS(L). The monotone cycle was not needed.

## Theorem (corridor, the M0 half of Merge)
Same hypotheses, case b. From R₂ = R*: E_i = L_i (identical class-0 a-steps) for 2 ≤ i ≤ k+1. At R_{k+2} either both
end or both take (0,b), with the same removed tiles and different created rhombi. Any other equal pair (E_j, L_j') has
j, j' ≥ k+3.
**Proof.** Lemma c0: at class 0, B and C remove the same tiles for each type; a-configurations coincide. Lemma pack:
the (S4) stopping test reads only R and the nests other than A, so it is target-blind at a shared rhombus. Both journeys
remove only M0 tiles, so different types would give two overlapping M0 tiles (Lemma ovl). Induction. B ≠ C enters only
through the b-rotations at the exit. Clause 3 uses finality plus the minimality of p.
