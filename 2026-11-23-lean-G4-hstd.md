## Task 1: `hstd`

**What `hstd` says in Lean.** `StdFrom ∅ (U ++ F)`, where:
- `U = skewCells (compl R C A) []` is `A^∨` read row by row.
- `F = holesWith tilde R C A B f` lists the holes in f̃-order.
- So each prefix of `U ++ F` must be a diagram.

Equivalently: `u_{A^∨}` followed by f̃ is a standard filling of `B^∨`. That is the last sentence of lem:rrstd, combined with `A^∨ ∪ rot(A/B) = B^∨`.

**It is not a consequence of `hbox` + `hcol`**, the hypotheses the old theorem kept besides `hstd`. It needs the paper's own standing hypotheses, written out:
- `hA`, `hB`: A and B are partitions (`getD` is antitone).
- `hBA`: B ⊆ A.
- `hrow`: f is weakly increasing along rows (adjacent cells).
- `hup`: f is strictly increasing up columns (adjacent cells).

This is lem:rrstd's "X semistandard on P/Q", made explicit. Nothing beyond what the paper assumes.
- `hcol` (column-injectivity) is kept, because `holesWith_spec` consumes it.
- With `hup` and convexity of skew shapes, `hcol` is derivable (gap G3 below). It is redundant, but I did not prove that today.

**New file `TworowD4Kernel/RRStd.lean`** (sorry-free):
- `stdFrom_of_pairwise` (generic): suppose κ is a diagram, L is nodup and disjoint from κ, κ ∪ L is a diagram, and no cell of L comes after one of its successors. Then `StdFrom κ L`.
- `pairwise_of_idxOf`, `mem_skewCells`, `compl_getD`, `mem_compl_cells`.
- `mem_union_rot`: `y ∈ A^∨ ∨ y ∈ rot(A/B) ↔ y.1 < R ∧ y.2 + B_{R-1-y.1} < C`, i.e. `A^∨ ∪ rot(A/B) = B^∨` cell by cell.
- **`hstd_of_ssyt`**, the target. The proof follows the tex:
  - `A^∨` row by row is lex-sorted, so it is standard from ∅.
  - `rot(A/B)` is disjoint from `A^∨`, and the union is the diagram `B^∨`.
  - Along F, the index is `std(rr f)` (`holesWith_spec`).
  - rr reverses both orders, so a predecessor has a strictly smaller (value, column) key:
    - north neighbour in A/B: strict value (`hup`);
    - east neighbour: weak value (`hrow`) plus a smaller column.

**New file `TworowD4Kernel/G4AssemblyStd.lean`**:
- **`thm_G4_of_slideOK'`**: `thm_G4_of_slideOK` with `hstd` replaced by `hstd_of_ssyt`. The old theorem is kept.
- The remaining named hypotheses are `hokR` and `hokF` (Fulton 1.2) only.

**Lesions** (kernel, `decide +kernel`, one instance each). In both, `hbox` and `hcol` hold and the stated violation holds, and `¬ hstd` is proved:
- `lesion_hup`: A=(1,1), B=∅, 2×1 box, f(0,0)=2, f(1,0)=1 (column decreasing upward).
- `lesion_hrow`: A=(2), B=∅, 1×2 box, f(0,0)=2, f(0,1)=1 (row decreasing eastward).

So neither semistandardness condition can be dropped, and `hstd` really did need more than the old hypothesis list.
