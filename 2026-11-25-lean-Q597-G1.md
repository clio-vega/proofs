## Sorry-free (0 sorries)
- `inc_eq`: each edge has exactly two incident triangles, `posTri e` (+1) and `negTri e` (−1). Incidence is defined from counterclockwise traversal.
- `bdry` (Finsupp boundary, Σ_t c(t)·inc(t,e)) = `bdryFun` (two-term formula c(t⁺) − c(t⁻)): `bdry_eq_bdryFun`.
- `const_of_bdryFun_eq_zero`: ∂c = 0 ⇒ c is constant (any function, not only finitely supported ones). This is the paper's connectivity argument, in place of the LEAN.md "extremal triangle" suggestion.
- **Core** `eq_zero_of_bdry_eq_zero (c : Tri →₀ ℤ) : (∀ e, bdry c e = 0) → c = 0`. Finiteness enters via `Infinite.exists_notMem_finset`.
- `eq_of_bdry_eq`: equal boundaries ⇒ equal chains.
- `G1_of_signedEdgeCount N p m (hSEC : ∀ e, bdry N e = bdry (deltaChain p m) e) : N t = [t ⊆ Δ(p,m)]`.
  **Named hypothesis `hSEC`**: this is the tex's "by edges / by tiles" count, which rests on Lemma D (KT lift, Purbhoo 0705.1184 §2.4). Neither is formalised. Finiteness of N is built in through the `Finsupp` type.
- Lesion `lesion_allOnes`: the all-ones function has bdryFun = 0 and is ≠ 0, so finite support is load-bearing.
