## What is proved (0 sorries)
- **`slides_colsW` (main).** Hypotheses: `U ++ F` is `Nodup`, `|U| = m`, and `X = valOf U` on `U`. Then for every prefix `A`,
  `colsW m |A| |F| (A ++ U ++ F) = A ++ V ++ U'`. Here `V` is the vacated-cell list of `slides revRule (m+1) U.toFinset X F`, and the word `U'`
  carries that run's final support (`toFinset`) and final values (`valOf`). The proof is induction on `F`. Each window
  step goes through `jdtRev_bridge` (on `U.reverse`, `valDec`), and a helper converts `valDec U.reverse` to `valOf U`.
  `Nodup` propagates because the cells of the slid word lie in `U ∪ {h}` (`jdtRev_mem`).
- **`slides_colsW_take`.** The `c = 0` reading: `V = take p (colsW m 0 p (U++F))`. The remaining `drop p` cells have the run's final support and values.
- **`V_colsW_of_slidesOK` (the session target).** Assume `SlidesOK revRule (m+1) S X F` (named hypothesis) and
  `std S X = valOf U` on `S = U.toFinset`. Then the cells the run vacates on the *semistandard* `X` are
  `take p (colsW m 0 p (U++F))`. The proof is `lemmaA_slides revRule`, then `slides_colsW_take`.
- **Fuel.** `PhiOut.phi` runs at fuel `R + C` and `colsW` at `m + 1`. `slides_fuel_eq` shows a reverse run does not
  depend on its fuel once the fuel covers `|S|` or covers every hole's anti-diagonal index `r + c`. The hole list must be
  nodup and avoid `S`. The reason: each reverse move lowers `r + c` by exactly 1, and it lowers
  `#{s ∈ S : r_s + c_s < r_h + c_h}` by at least 1. Supports keep their size and stay inside `S ∪ {h}`, which is `slide_support`, proved for any rule.
  **`V_colsW_of_slidesOK_fuel`** states the target at any fuel `k' ≥ r + c` of every hole. `SlidesOK` is still taken at fuel `m+1`.

## Lesions and controls (kernel `decide +kernel`)
- `control_take`: `U=[(0,0)]`, `F=[(0,1),(1,0)]`. A real move happens (the first hole slides west), and `V = [(0,0),(1,0)] = take 2 colsW`.
- `lesion_hole_order_reversed`: with the holes `F` reversed, the run vacates `[(0,0),(0,1)]`, which is not equal to `colsW`'s `[(0,0),(1,0)]`.
- `lesion_values_reversed`: with values `valDec U` (entry order flipped) at `U=[(0,1),(1,0)]`, hole `(1,1)`, the run goes south instead of west and the glue fails.
  The true values agree on the same instance.
- `lesion_fuel_zero`: at fuel 1 (= the anti-diagonal bound) the run agrees with `colsW`. At fuel 0 nothing moves and the glue fails.
The lesion instances satisfy `Nodup` and the value hypothesis, so each lesion fails because of the property it changes, not because a precondition broke.
